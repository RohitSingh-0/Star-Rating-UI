# ⭐ Star Rating UI

An interactive star rating component built using HTML, CSS, and JavaScript.

This was one of my first frontend projects, developed during my first year of college. While building it, I started learning how HTML structures a webpage, how CSS styles the user interface, and how JavaScript adds interactivity through DOM manipulation and event handling.

## 📌 About the Project

Star Rating UI is a simple and interactive feedback component that allows users to select a rating from 1 to 5 stars and submit their response.

After submission, the interface dynamically changes to display a thank-you screen.

The project helped me understand the relationship between HTML, CSS, and JavaScript in building interactive web interfaces.

## ✨ Features

* Select a rating from 1 to 5 stars.
* Interact with the rating component.
* Submit the selected rating.
* Display a thank-you screen after submission.
* Update the interface dynamically using JavaScript.
* Simple and user-friendly interface.

## 🛠️ Technologies Used

* **HTML5** — Structured the webpage and its content.
* **CSS3** — Styled the interface, rating component, and layout.
* **JavaScript** — Implemented rating selection, event handling, DOM manipulation, and UI updates.
* **SVG** — Used scalable vector graphics for visual assets.

## 🚀 Getting Started

No additional packages or frameworks are required to run this project.

### Prerequisites

* A modern web browser.
* A code editor such as Visual Studio Code (optional).

### Installation and Setup

1. Clone the repository:

   git clone https://github.com/RohitSingh-0/Star-Rating-UI.git

2. Open the project folder:

   cd Star-Rating-UI

3. Open `index.html` in your browser.

You can also open the project folder in Visual Studio Code and use a local development extension such as Live Server.
